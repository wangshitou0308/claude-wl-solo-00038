# 潮滩返程窗口核对

面向结伴赶海、步速与涉水把握不同的中老年沿海居民：以**全组最慢者**核验整条去返流程，
避免走到折返点才发现必经浅沟已被涨潮截断。纯前端应用，所有潮汐抄录、路线与操作进度
**只保存在本机浏览器（IndexedDB）**，不上传任何服务器。

## 运行

```bash
npm install
npm run dev      # 本地开发，默认 http://localhost:5173
```

其他命令：

```bash
npm run build    # 类型检查 + 生产构建
npm run check    # 核心核验算法的数值自检脚本
```

## 使用流程

1. **潮汐抄录**：录入当地发布的潮高时刻点（时刻 + 潮高厘米）。应用只在**相邻潮点之间
   线性插值**，首尾点之外一律不推算；发布中断可标记“数据缺口”，行程触及缺口即判阻断。
2. **路线 · 安全点 · 同行者**：
   - 从岸到折返点依次建立分段，填写沟床高程、**可通行高程**（安全阈值）、去/返程
     “快—慢”耗时范围；
   - 标明**安全点/休息点**——全组停留只允许发生在这些点（含出发岸与折返点）；
   - 录入每位同行者的步速系数与个人涉水安全余量。
3. 自动核验规则：对每段每次穿越，要求
   **该穿越时段内最高潮位 + 个人余量 < 该段可通行高程**（取时段峰值，因分段线性插值，
   峰值只可能出现在穿越端点或潮点时刻）。任何人、任何一段不满足即不可行。
4. **结果区**列出所有**可出发区间**及每个区间最晚出发时的**最晚折返（开返）时刻**与最晚
   到岸时刻；拖动出发时刻滑块，SVG 即时展示：
   - 上图：潮位曲线、各段通行高程阈值、每人去返泳道（穿越条/停留圆点）、红色竖线标注
     **最先关闭的路段**与峰值时刻；
   - 下图：潮滩剖面、当前潮位水面、各段阈值、安全点与**各人实时位置**。
   另设观察时刻游标，可跳到“最先关闭时刻”复盘涨潮过程。
5. **阻断定位**：无可行区间或所选时刻不可行时，明确指出是哪一段、去程还是返程、
   潮位截断 / 数据缺口 / 超出已抄录区间，并给出全区间扫描的分段统计，不向区间外推算。
6. 输入框编辑**可撤销/重做**（按钮或 Ctrl+Z / Ctrl+Y）；改动潮点或路线后结论自动重算，
   旧结论即废止。刷新页面后自动从 IndexedDB 续做；可**打印同行核对卡**随身携带。

## 技术栈

Vue 3 + TypeScript + Vite，图形为手写 SVG（无图表库），本地存储为 IndexedDB（防抖写入）。

核心模块：

- `src/lib/tide.ts`：潮点线性插值、区间外/缺口判定、时段最高潮位
- `src/lib/planner.ts`：单人时间线构建、全组核验、分钟级扫描与可行区间提取
- `src/lib/sim.ts`：任意时刻人员在剖面上的位置
- `src/lib/db.ts`：IndexedDB 读写
- `src/components/`：潮汐/路线录入、结果面板、SVG 剖面、打印核对卡

> 高程基准（如当地海图基准面）请在潮高与各段高程间保持统一；本工具只做机械核验，
> 不替代现场判断，天气、风浪等因素需另行留足余量。
